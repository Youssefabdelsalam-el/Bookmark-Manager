# استخدامات كل مكتبه 

tailwindcss: بستخدمها عشان اعمل style للموقع واظبط الالوان والاحجام والمسافات عن طريق classes جاهزه بدل ما اكتب css 

react-icons: بستخدمها عشان أضيف أيقونات جاهزة للموقع

formik: بستخدمها عشان اقدر اتعامل مع الفورم واتحكم في البيانات الي المستخدم بيكتبها 

yup: بستخدمها عشان اتاكد ان البيانات الي المستخدم دخلها صح بنفس الشروط الي محددها

react-router-dom: دي الي بتخليني اقدر اتحكم في التنقل بين صفحه وصفحه من غير ما الموقع يعمل Reload كل مره 

axios: دي بستخدمها عشان اقدر اتعامل مع الباك ايند واقدر اخد من بيانات وابعتله بيانات 

zustand: بستخدمها عشان لو عندي بيانات مشتركه بين اكتر من كمبوننت اقدر اخزنها في مكان واحد واخلي اي كمبوننت يقدر يوصلها بدل ما استخدم الي props
